# 隅读 1.0.0 测试记录

测试日期：2026-09-07（北京时间）。目标系统：Windows 10 / 11 x64。

## 环境与结论

在 Linux 主机上交叉编译 Windows GUI EXE，使用 Wine 11.0 运行真实 Win32 窗口、GDI 分页绘制、系统热键与文件对话框。另执行平台无关的分页单元测试和 Windows 目标的静态检查。截图来自实际运行窗口，已人工查看欢迎页、正文、设置、深色模式和缩放后的设置布局。

最终自动窗口检查 **44 / 44 通过**，进程正常退出。百万字合成小说共 4,167 页，本次分页耗时 58 ms。移动窗口保留手动字数上限、拉伸恢复自适应，以及快捷键输入框录制均已覆盖。

本记录是兼容层验证，不等同于真实 Windows 设备验收。Windows 10 / 11 原生机器、不同显卡的独占全屏环境和多显示器热插拔尚未现场验证。

## 自动检查命令

```sh
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go vet -unsafeptr=false ./...
wine dist/FloatReader.exe --smoke-test
```

核心单元测试验证每个字符连续且只消费一次、页高和字数上限、空文本、长段落、Unicode 字符、换行规范化、缩放后的阅读锚点。Windows 回调转换系统指针的模式不适用 `unsafeptr` 检查，该项按项目需要关闭。

Wine 不自带微软雅黑。测试模式临时加载宿主的 Noto Sans CJK 字体，以便实际检查中文显示；普通 Windows 运行使用 Microsoft YaHei UI，不读取该测试字体路径。

## 交付边界

- 置顶使用系统支持的 `HWND_TOPMOST`；不宣称覆盖 UAC 安全桌面、锁屏或独占全屏。
- 本版为 x64，无安装器，不需要管理员权限。未进行商业 Authenticode 签名。
- 程序不联网；小说内容保留在原文件中。自动测试使用独立配置，不覆盖正常用户配置。
- `SHA256SUMS.txt` 用于校验 EXE 和交付 ZIP。交付 ZIP 已解压校验，内部 EXE 与所测文件一致。
