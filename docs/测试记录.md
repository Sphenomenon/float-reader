# 测试记录

版本：1.0.3。日期：2026-09-10。

## 环境

在 Linux 上编译 Windows x64 EXE，用 Wine 11.0 运行。还没有在 Windows 10 / 11 机器上测试，多显示器热插拔也未测试。

Wine 中的中文截图使用 Noto Sans CJK，Windows 下程序使用 Microsoft YaHei UI。测试时会模拟键盘操作，运行期间不要手动操作测试窗口。

## 结果

分页单元测试、Windows 静态检查和 53 项窗口检查通过。窗口检查包括分块导入、翻页、老板键、尺寸和字数设置、背景与文字分层透明、快捷键冲突、进度保存，以及 200% 缩放下设置按钮是否超出屏幕。

数据见 [qa-report.json](qa-report.json)。长文本测试使用 100 万字的重复文本，检查首屏只读取一个 64 KB 文件块。移动窗口的检查会对比读取次数，确认位置变化没有触发重新加载。

方向键用 Win32 消息检查，全局快捷键用系统键盘事件检查。宿主是平铺窗口管理器，切换焦点时可能改变阅读窗口大小，因此全局翻页检查比较阅读位置是否前进。

## 复现

```sh
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go vet -unsafeptr=false ./...
wine dist/FloatReader.exe --smoke-test
```

Windows 下直接运行 `FloatReader.exe --smoke-test`。测试使用独立配置，结果和截图写入 EXE 同目录的 `qa/`。有检查失败时，进程返回非零。

分页单元测试检查字符是否遗漏或重复、换行和长段落、单页按需布局、页高与字数上限，以及缩放后的阅读位置。静态检查关闭 `unsafeptr` 项，因为 Win32 回调需要将 `LPARAM` 转回系统结构体指针。

发布包中的 EXE 会与测试版本核对 SHA-256；下载页的 `SHA256SUMS.txt` 可用于文件校验。
