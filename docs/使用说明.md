# 隅读使用说明

适用于 Windows 10 / 11，64 位。

## 打开小说

解压下载的压缩包，双击 `FloatReader.exe`。点击“导入 TXT”选择小说，或直接把文件拖进窗口。没有现成的 TXT，可以先打开包里的示例小说。

点击正文后，按右 / 下方向键读下一页，左 / 上方向键回上一页。鼠标滚轮和底部的左右按钮也能翻页。

支持 UTF-8、带 BOM 的 UTF-16 和 GB18030 / GBK 编码，单个文件最大 512 MB。如果文字乱码，可以先用文本编辑器另存为 UTF-8 再导入。程序按块读取文件，内存里只保留当前页和最近的翻页位置。

## 窗口大小和每页字数

拖住顶部“隅读”或书名附近移动窗口。拖动边缘或角落改变大小，正文会重新分页，底部会显示这一页的字数。

右上角的“设置”也能直接输入宽高。修改“每页目标字数”时，程序会调整窗口大小，让一页尽量装下这些字。段落空行会占位置，所以实际字数可能少一些，但不会超过设定的上限。屏幕放不下时，需要减少字数或缩小字号。

只移动窗口不会重新读取或分页。拉伸窗口，或修改字号、行距后，字数改为随窗口大小变化，程序只重排当前页并保留阅读位置。

配色有暖白、深色和浅蓝。不透明度可以设为 0–100；设为 0 时，背景、标题、设置按钮和底栏会隐藏，只显示正文。此时右键正文可以打开设置，也可以选择“移动窗口…”。修改后点击“保存设置”；点“取消”则放弃这次修改。

## 隐藏和退出

默认老板键是 Ctrl + Alt + 空格。在其他软件里按也有效：按一次隐藏，再按一次显示。打开着的设置和文件选择窗口会一起隐藏。

找不到窗口时，可以点右下角托盘里的隅读图标。图标可能收在“^”菜单里。再次双击 `FloatReader.exe` 也能找回窗口，不会多开一个阅读器。

要完全退出，右键正文或托盘图标，选择“退出隅读”。

置顶适用于普通桌面窗口。UAC 安全提示、锁屏和独占全屏受 Windows 限制，阅读器无法盖住它们。

## 改快捷键

打开设置，点击某个快捷键输入框，直接按下新按键，再点“保存设置”。上一页、下一页、老板键、导入 TXT 和打开设置都能改。

老板键要用带 Ctrl、Alt 或 Shift 的组合，或者单独使用 F1–F11。Tab 留作设置项之间的切换；Win 组合键、F12 和系统保留组合不能设置。重复或已被其他软件占用的组合会提示修改，原设置保留。

勾选“在其他软件里也能翻页”后，设置中的两个翻页键会全局生效。建议设成 Ctrl + Shift + → 这样的组合，以免占用工作软件的方向键。默认的上下方向键只在局部翻页模式下作为左右键的替代。

隐藏时，全局翻页键会释放；显示时重新启用。如果这期间被其他程序占用，阅读器会关掉全局翻页并提示重新设置，老板键仍可使用。

## 阅读记录

下次启动会打开上次的小说，接着上次的位置读。右键菜单中可以切换最近读过的文件。小说移动或删除后，需要重新导入。

设置和阅读位置保存在 `%APPDATA%\FloatReader\settings.json`。程序不联网，也不修改原 TXT 文件。需要清除记录时，先退出，再删除配置目录。
