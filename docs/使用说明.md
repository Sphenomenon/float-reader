# 隅读 · 使用说明

适用：Windows 10 / 11，64 位。

## 第一次使用

1. 把压缩包解压到一个文件夹，双击 `FloatReader.exe`。
2. 点击“导入 TXT”，选择你的小说。也可以直接把 TXT 拖到阅读窗口里。
3. 点击阅读窗口后，用右 / 下方向键翻到下一页，左 / 上方向键翻到上一页。鼠标滚轮和窗口底部的左右按钮也可翻页。

程序不需要安装其他运行环境。首次启动显示空白欢迎页属于正常状态；导入后才显示正文。压缩包附带一篇可用于演示的示例小说。

## 移动窗口与调整每页字数

拖住顶部“隅读”或书名附近移动整个窗口。拖动任一边缘或角落改变宽高，正文会重新分页，底部字数同步变化，当前阅读位置会保留。

点击右上角“设置”，也可以直接输入宽度、高度和“每页目标字数”。修改目标字数会自动匹配窗口尺寸；单页内容不会超过该字数上限。由于标点、英文、段落空行和行高不同，实际字数以底部显示为准，可能低于目标值。较大的目标超出屏幕容纳范围时会提示修改。

手动拖动尺寸后，阅读器恢复按实际区域自适应，不再保留之前的固定字数上限。更改字号或行距后也会重新适配。

## 老板键：一键隐藏，再按一次恢复

默认是 **Ctrl + Alt + 空格**。

无论你正在使用哪个普通桌面软件，按下该组合键即可隐藏阅读窗口；正在打开的设置和导入文件对话框也一起隐藏。再按一次恢复。

隐藏后，任务栏不保留阅读窗口按钮。右下角系统托盘仍有隅读图标，可能收在“^”展开菜单里。点击托盘图标也能显示 / 隐藏；右键可打开设置、导入、最近阅读或退出。再次双击程序也可找回已经运行的窗口。

## 自定义快捷键

1. 打开设置，点击需要修改的快捷键输入框。
2. 直接按下希望使用的按键或组合键，例如 Ctrl + Shift + →。
3. 点击“保存设置”。重复组合或被其他软件占用的全局组合会提示修改，原设置保留。

可以自定义：下一页、上一页、老板键、导入 TXT、打开设置。老板键始终全局生效，建议使用 Ctrl / Alt / Shift 的组合键，或者 F1–F11。Tab 用来在设置项之间移动，Win 组合键、F12 和系统保留组合不能设置。

如果希望不点击阅读窗口也能翻页，勾选“在其他软件中也能用翻页快捷键”。建议使用带 Ctrl / Alt / Shift 的组合，避免占用工作软件的方向键。全局模式只使用输入框中设置的两组翻页键。窗口隐藏时会释放翻页键，恢复时自动重新注册；如被其他程序抢占，会提示重新设置。

## 配色、透明度与进度

设置提供“纸间 · 暖白”“夜航 · 深色”“晴空 · 雾蓝”三种配色，可调整字号、行距和不透明度。点击保存后生效；取消会放弃修改。

阅读位置与偏好自动保存。下次启动会打开上次的小说并恢复位置。请保留原 TXT 文件；如果移动或删除了文件，需要重新导入。通过右键菜单可以切换最近阅读的小说。

## 退出和常见问题

- **完全退出**：右键阅读区域或系统托盘图标，选择“退出隅读”。隐藏不等于退出。
- **快捷键没反应**：先确认阅读器有焦点，或已开启全局翻页；老板键如被其他软件占用，请在设置中换一个组合。
- **文件显示不正确**：支持 UTF-8、带 BOM 的 UTF-16、GB18030 / GBK。罕见编码可先用文本编辑器另存为 UTF-8 后导入。单文件最大 32 MB。
- **找不到窗口**：点击系统托盘图标，或再次运行 `FloatReader.exe`。重复运行不会打开第二个阅读器。
- **无法覆盖某些画面**：普通桌面窗口使用系统置顶；UAC 安全提示、锁屏和独占全屏属于 Windows 的系统限制。

设置和进度文件位置：`%APPDATA%\FloatReader\settings.json`。软件本身不联网，不上传小说，也不修改原始文件。
